# Playwright CLI 使用规则（必须严格遵守）

## 浏览器配置
- 使用本机已安装的Chrome浏览器，禁止其他浏览器
- 打开浏览器必须添加 `--persistent` 参数，保持窗口可见
- 保留 cookies、session 等登录状态，禁止清除浏览器数据
- 保持窗口正常大小，禁止最小化或关闭

## MCP连接要求
- 通过 `playwright-cli attach --extension` 连接已登录的浏览器会话
- 保持会话不关闭，复用同一个会话，禁止频繁断开重连
- 连接异常重试不超过3次，仍失败及时反馈

## 命令执行规范
- 执行操作前必须 `playwright-cli snapshot` 获取页面快照确认元素
- 含特殊字符、空格或中文必须用英文双引号包裹
- iframe 内操作需先定位 iframe，禁止直接全局输入
- 检查执行结果成功后再下一步，出错及时排查
- 禁止危险命令，防止浏览器/系统崩溃

## 安全规范
- 禁止操作隐私/敏感内容，禁止获取泄露账号密码
- 不可逆操作前确认目标正确，避免误操作
- 禁止访问无关网站，禁止无关操作
- 禁止修改用户浏览器配置、书签

## 异常与调试
- 页面加载超时等待3-5秒再重试，避免重复提交
- 元素定位失败重新获取快照确认ref，不盲目重试
- 弹窗先确认内容再处理，不忽略直接继续
- 异常优先用 `playwright-cli snapshot` 查看状态
- 查看日志用 `playwright-cli console`，必要时截图保存
- 不随意修改系统/项目配置，优先调整操作流程
